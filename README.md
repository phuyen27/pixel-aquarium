# Pixel Aquarium

A small pixel-style aquarium game built with HTML, CSS and JavaScript.

# link: https://pixaqua.netlify.app/

## Features

- Buy and raise different fish.
- Feed fish and collect coins.
- Unlock different aquarium tanks.
- Day and night cycle.
- Save and restore game data using a backup code.
- Responsive layout.

## How to run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start playing.

No build tools or dependencies are required.

## Project structure

- `index.html`: Main HTML structure.
- `css/style.css`: Game styles.
- `js/data.js`: Fish and aquarium data.
- `js/sprites.js`: Pixel sprites and fish rendering.
- `js/scene.js`: Aquarium scene and decorations.
- `js/game.js`: Game state, simulation and rendering loop.
- `js/ui.js`: Shop, tank selection and user interface.
- `js/save.js`: Save and restore functions.

## Technologies

- HTML5
- CSS3
- JavaScript
- Canvas API
- LocalStorage

## Save data

Game data is stored in the browser's LocalStorage.
Use the backup button in the game to export or restore data.
